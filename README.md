# Etch-a-sketch

This project was part of the Odin Project's foundation course. The goal was to recreate the etch-a-sketch toy, using HTML, CSS, Flexbox, and JavaScript. 

## Demo

[For a limited time only] you can check out the live version [here](https://jason-p-nguyen.github.io/etch-a-sketch/). 


## Features

- Grid generator 
- Random color generation
